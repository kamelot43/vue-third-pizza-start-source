🍕 Конструктор пиццы (Pizza App)
Интерактивное веб-приложение для создания пиццы своей мечты.
Собирайте пиццу из разнообразных ингредиентов, добавляйте в корзину, оформляйте заказ и просматривайте историю. Проект построен на современном стеке Vue 3 + Node.js и полностью контейнеризирован для удобства разработки и деплоя.

✨ Возможности
Конструктор пиццы – выбор теста (тонкое/толстое), размера (23/32/45 см), соуса (сливочный/томатный) и до 15 видов ингредиентов (до 3 порций каждого).
Drag & Drop – ингредиенты можно перетаскивать прямо на изображение пиццы.
Визуализация в реальном времени – добавленные ингредиенты отображаются на пицце с анимацией.
Корзина – просмотр добавленных пицц, изменение количества, редактирование или удаление.
Оформление заказа – указание адреса доставки, контактного телефона, выбор типа доставки.
История заказов – список всех оформленных заказов с возможностью повторить или удалить.
Авторизация и регистрация – JWT-аутентификация, защита личных данных.
Адаптивный дизайн – удобная работа на любых устройствах.

🛠 Стек технологий
Frontend: Vue 3, Pinia, Vue Router, Vite, SCSS, Drag & Drop API.

Backend: Node.js, LoopBack 4, PostgreSQL, JWT.

Инфраструктура: Docker, Docker Compose.

🚀 Быстрый старт
Требования
Docker

Node.js 16 или выше (рекомендуется nvm)

GNU Make (опционально, для удобных команд)

Установка и запуск
Вариант 1: Использование GNU Make (проще всего)
bash


# Установка зависимостей
```
make install_dependencies
```

# Запуск всех сервисов (база данных, бэкенд, фронтенд)
```
make start_project
```
После запуска:

Фронтенд: http://localhost:8080

Бэкенд API: http://localhost:3000

Вариант 2: Ручной запуск (без Make)
1. База данных (через Docker):

```
bash
docker run --name pizza-db -e POSTGRES_PASSWORD=psql -e POSTGRES_DB=pizza -p 5432:5432 -d postgres
```
2. Бэкенд:

```
bash
cd backend
npm ci
npm start
```

3. Фронтенд:

```
bash
cd frontend
npm ci
npm run dev

```
Вариант 3: Полный запуск через Docker Compose
```
bash
docker compose down -v   # (опционально) очистить тома
docker compose build
docker compose up
```
🔐 Тестовый пользователь
Для входа в приложение можно использовать предустановленного пользователя:

text
email: user@example.com
password: user@example.com
Данные для входа можно изменить в файле backend/src/factory/users.json.

📚 Документация API
После запуска бэкенда документация OpenAPI доступна по адресу:

text
http://localhost:3000/explorer/
🧪 Запуск тестов и линтинг
bash
# фронтенд
```
cd frontend
npm run test:unit   # юнит-тесты
npm run lint        # проверка кода
```

# бэкенд (только линтинг)
```
cd backend
npm run lint
```
📦 Сборка продакшн-версии
```
bash
cd frontend
npm run build
```

Готовая статика будет в папке frontend/dist. Её можно развернуть на любом статическом хостинге (Vercel, Netlify и др.), не забыв задать переменную окружения VITE_API_URL с адресом бэкенда.

🎨 Шаблон и вёрстка
В папке template находится готовая вёрстка проекта. Для её просмотра выполните:

```
bash
cd template
npm ci
npm start
```
Вёрстка будет доступна по адресу http://localhost:9999.
